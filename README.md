# Higher Education Trends Explorer

Final project for the MBAxMS Python Bootcamp (Fall 2026).

A Python tool for pulling public U.S. higher education data (IPEDS via the Urban
Institute Education Data Explorer) and visualizing how the sector has changed over time.

See [proposal.md](proposal.md) for the full proposal and group members.
